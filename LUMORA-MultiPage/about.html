About LUMORA

A simple platform for meaningful learning

What is LUMORA?

LUMORA is a simple educational platform where students can explore different subjects, discover educational lectures and find useful learning resources.

The main purpose is to encourage meaningful learning instead of endless social media scrolling.

Frequently Asked Questions

Is LUMORA free?

Yes, this is a student project and everything is free.

Do the login and lectures really work?

No. This is a design project made with only HTML and CSS, so login and videos are for demo only.

Which technologies are used?

HTML5, CSS3 and Bootstrap 5. No JavaScript is used.
